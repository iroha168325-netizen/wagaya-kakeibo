わが家の写真家計簿（試作版）
このフォルダはスマホ用の家計簿Webアプリです。

重要：
・この版は写真を表示して手入力する試作版です。レシート/通帳の自動文字読み取り(OCR)はまだ搭載していません。
・記録は利用中のブラウザの端末内保存(localStorage)です。別端末とは同期されません。
・本格的なホーム画面追加(PWA)には、HTTPS対応のWebサーバーへこのフォルダ内のファイルを配置する必要があります。
・銀行口座番号、暗証番号、ログイン情報は入力しないでください。
・通帳や明細の読み取り結果は必ず原本と照合してください。

使い方：
1. index.htmlをブラウザで開くと基本画面を確認できます。
2. カメラ撮影/写真選択で画像を表示します。
3. 写真を見ながら日付・内容・金額・分類を入力し「この内容で登録」。
4. 月別集計、CSV書き出し、JSONバックアップが使えます。
5. ホーム画面追加はHTTPSで公開後、Android Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選びます。
